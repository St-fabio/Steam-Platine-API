# Steam-Platine-API

A rest API using express.js to get and share data about steam achievements stats.

### How to install

1. Clone the repo

```bash
git clone https://github.com/St-fabio/Steam-Platine-API.git
cd /Steam-Platine-API
```

2. Install dependencies

```bash
npm install
```

3. Create a `.env` file

4. Set the variables like in `.env_example`
you need to have a steam API key, If you don't have one follow this [steam API Key guide](https://steamcommunity.com/dev/apikey)

### How to launch

```bash
node .
```

L'api est accessible sur le port 3000
